Practice Questions for Revision

1. What is the purpose of the box model?

It defines how an element’s content, padding, border, and margin are arranged.

2. What is the difference between margin and padding?

Margin creates space outside an element, while padding creates space inside it.

3. What is Flexbox used for?

It is used to arrange items in rows or columns easily.

4. What is Grid used for?

It is used for two-dimensional layouts with rows and columns.

5. What is the use of media queries?

They make websites responsive for different screen sizes.

6. What are CSS variables?

They are custom properties that let you reuse values throughout the stylesheet.

7. What does z-index control?

It controls the stacking order of overlapping elements.

8. What is the difference between display: block and display: inline?

Block elements take full width and start on a new line, while inline elements stay in the flow and only take as much width as needed.
